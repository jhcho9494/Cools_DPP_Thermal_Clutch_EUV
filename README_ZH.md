# Cools DPP Thermal Clutch EUV

## Cools 专利冷却技术可使 DPP 扩展至并超越 LPP 级 EUV 功率

> **DPP 失败，并不是因为放电等离子体在物理上必然劣于 LPP。**  
> **真正的问题是电极无法承受并排出热量。**

[English](README.md) · [한국어](README_KR.md)

## 核心主张

激光产生等离子体（Laser-Produced Plasma，LPP）依靠兆瓦级二氧化碳（CO₂）驱动激光器、光束传输系统、锡液滴发生器、自由空间等离子体控制和碎屑抑制系统来实现高功率极紫外（Extreme Ultraviolet，EUV）光源。

放电产生等离子体（Discharge-Produced Plasma，DPP）通过电放电直接产生锡等离子体，因此能够省去上述复杂链路中的大部分设备。但在高功率扩展过程中，等离子体面对电极的热积累、侵蚀、弧根不稳定、氢损伤和碎屑成为决定性瓶颈。

**Cools 的主张是：将 Cools 专利导热冷却架构应用于 DPP 电极，解除这一热上限。电极一旦能够承受更高输入功率和更高重复频率，DPP 就可以用更高绝对功率抵消较低的等离子体转换效率，并扩展至超越 LPP 级 EUV 输出。**

## 错误的比较方式

传统比较只关注等离子体转换效率（Conversion Efficiency，CE）：

| 光源 | 代表性等离子体 CE |
|---|---:|
| LPP | 约 6% |
| 锡 DPP | 约 2% |

但这一比较并不完整。

真正的系统级问题应当是：

> **相对于墙插输入功率、系统体积和热极限，有多少 EUV 功率能够到达中间焦点（Intermediate Focus，IF）？**

LPP 必须承担驱动激光器效率、光束传输损失、液滴系统、碎屑抑制系统透过损失、精密时序控制以及光学污染管理。DPP 的等离子体 CE 较低，但它采用直接电驱动，并且可以通过固体电极结构有目的地将热量导出。

## 传统 DPP 为何无法继续扩展

```mermaid
flowchart LR
    A[提高放电输入] --> B[电极热积累]
    B --> C[表面侵蚀与弧根不稳定]
    C --> D[碎屑与集光系统污染]
    D --> E[输入功率与重复频率上限]
    E --> F[较低绝对 EUV 输出]
```

因此，传统 DPP 的根本问题并不只是“CE 较低”。在能够利用更高电输入之前，电极首先达到了热极限。

## Cools 改变了什么

Cools 采用方向不对称的热结构：**EUV 向前，热量向后。**

```mermaid
flowchart LR
    P[脉冲放电热] --> F[等离子体面对热缓冲区]
    F --> C[高导热冷指]
    C --> M[后部微通道排热]
    M --> H[允许输入功率与重复频率提高]
    H --> E[绝对 EUV 输出提高]
```

该架构把两种热事件分开处理：

1. **瞬态脉冲热**由等离子体面对区域缓冲；
2. **累积平均热**通过后部导热通道和微通道冷却连续排出。

目标并不只是延长电极寿命，而是**解除使 DPP 长期受限于 LPP 以下的输入功率上限。**

## 从效率竞争转向绝对功率扩展

Cools 的逻辑如下：

```text
传统 DPP
电极热极限 → 输入受限 → 重复频率受限 → 绝对 EUV 功率低

Cools 冷却 DPP
热极限解除 → 输入提高 + 重复频率提高
→ 用热裕量抵消较低 CE
→ 达到 LPP 级并进一步超越 LPP 的绝对 EUV 功率
```

核心可归纳为一句话：

> **当允许输入功率和重复频率显著提高时，较低 CE 并不必然意味着较低 EUV 输出。**

## 支撑高功率运行的辅助功能

冷却是首要扩展杠杆。以下功能用于在高功率条件下稳定电极：

- **自更新锡表面：** 不让等离子体损伤永久积累为固定缺陷，而是持续恢复表面；
- **F-locked 边界：** 阻止氢进入电极本体，减少鼓泡、剥离和碎屑；
- **环形电极：** 打开光轴中心，实现前向轴向集光；
- **可更换碎屑屏蔽：** 降低集光侧污染并提高可维护性。

这些并不是彼此独立的产品概念，而是一个统一架构：**在 Cools 专利冷却技术提高允许功率的同时，保持 DPP 电极稳定。**

## 战略意义

Cools 并不是在提出另一个小幅改进的 DPP 电极。

> **Cools 将其专利导热冷却架构应用于阻止 DPP 高功率扩展的关键部件——等离子体面对电极。**

当热上限被解除后，DPP 仍然保留相对于 LPP 的结构优势：

- 直接电驱动；
- 不需要兆瓦级 CO₂ 激光链；
- 不需要高精度液滴发生器；
- 系统复杂度更低；
- 占地更小；
- 通过固体结构直接排热。

因此，可以形成一种更简单、同时有潜力达到更高功率的 EUV 光源架构。
