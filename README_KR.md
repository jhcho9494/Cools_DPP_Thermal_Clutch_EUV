# 쿨스 DPP 서멀클러치 EUV

## 쿨스 특허 냉각기술이 DPP를 LPP급 이상으로 확장한다

> **DPP가 방전 플라즈마 자체의 열등함 때문에 패배한 것이 아닙니다.**  
> **전극의 열을 제거하지 못했기 때문에 패배했습니다.**

[English](README.md) · [中文](README_ZH.md)

## 핵심 명제

레이저 생성 플라즈마(Laser-Produced Plasma, LPP)는 메가와트급 이산화탄소(CO₂) 구동 레이저, 빔 전달계, 주석 드롭릿 발생기, 자유공간 플라즈마 제어, 데브리 저감계를 결합한 복잡한 시스템으로 고출력 극자외선(Extreme Ultraviolet, EUV) 광원을 구현합니다.

방전 생성 플라즈마(Discharge-Produced Plasma, DPP)는 주석 플라즈마를 전기방전으로 직접 발생시키므로 이 복잡한 구동체인의 상당 부분을 제거할 수 있습니다. 그러나 고출력화 과정에서 플라즈마 대면 전극의 열축적, 침식, 아크풋 불안정, 수소 손상과 데브리가 결정적인 한계가 되었습니다.

**쿨스의 주장은 명확합니다. 쿨스의 특허 전도냉각 아키텍처를 DPP 전극에 적용해 이 열천장을 제거하면, 더 높은 입력전력과 반복률을 사용할 수 있고, 낮은 플라즈마 변환효율을 더 높은 절대출력으로 상쇄하여 LPP급을 넘어설 수 있습니다.**

## 잘못된 비교 기준

종래 비교는 플라즈마 변환효율(Conversion Efficiency, CE)만 봅니다.

| 광원 | 대표 플라즈마 CE |
|---|---:|
| LPP | 약 6% |
| 주석 DPP | 약 2% |

그러나 이것만으로는 시스템 경쟁력을 설명할 수 없습니다.

실제 비교 기준은 다음이어야 합니다.

> **벽전원 입력, 시스템 크기와 열한계 대비 중간초점(Intermediate Focus, IF)에 도달하는 EUV 출력이 얼마인가.**

LPP는 구동 레이저 효율, 빔 전달 손실, 드롭릿 시스템, 데브리 저감계의 투과 손실, 정밀 타이밍 제어와 광학 오염관리를 모두 부담합니다. DPP는 플라즈마 CE가 낮지만 직접 전기구동이며, 발생열을 고체 전극을 통해 의도적으로 뽑아낼 수 있습니다.

## 종래 DPP가 고출력화되지 못한 이유

```mermaid
flowchart LR
    A[방전 입력 증가] --> B[전극 열축적]
    B --> C[표면 침식과 아크 불안정]
    C --> D[데브리와 집광계 오염]
    D --> E[입력·반복률 상한]
    E --> F[낮은 절대 EUV 출력]
```

즉 종래 DPP의 본질적 문제는 단순히 낮은 CE가 아니었습니다. 더 높은 전기입력을 사용하기 전에 전극이 먼저 열한계에 도달했습니다.

## 쿨스가 바꾸는 것

쿨스는 **EUV는 앞으로, 열은 뒤로** 보내는 방향 비대칭 열구조를 적용합니다.

```mermaid
flowchart LR
    P[펄스 방전열] --> F[플라즈마 대면 열완충부]
    F --> C[고전도 콜드핑거]
    C --> M[후방 마이크로채널 열배출]
    M --> H[허용 입력·반복률 상승]
    H --> E[절대 EUV 출력 상승]
```

이 구조는 두 종류의 열을 분리해 처리합니다.

1. **순간 펄스열**은 플라즈마 대면부가 완충합니다.
2. **누적 평균열**은 후방 전도경로와 마이크로채널을 통해 지속적으로 제거합니다.

목표는 단순히 전극 수명을 늘리는 것이 아닙니다. **DPP를 LPP 아래에 묶어두었던 입력전력 상한을 해제하는 것**입니다.

## 효율 경쟁에서 절대출력 경쟁으로

쿨스의 논리는 다음과 같습니다.

```text
종래 DPP
전극 열한계 → 입력 제한 → 반복률 제한 → 낮은 절대 EUV 출력

쿨스 냉각 DPP
열한계 해제 → 입력 증가 + 반복률 증가
→ 낮은 CE를 열적 헤드룸으로 상쇄
→ LPP급 및 LPP 초과 절대 EUV 출력
```

핵심은 한 문장입니다.

> **허용 입력전력과 반복률을 크게 올릴 수 있다면, 낮은 CE가 반드시 낮은 EUV 출력을 의미하지 않습니다.**

## 고출력 운전을 지지하는 보조기능

냉각이 1차 고출력화 수단입니다. 다음 구조는 고출력 조건에서 전극을 안정화합니다.

- **자가재생 주석 표면:** 플라즈마 손상을 고정 결함으로 축적하지 않고 표면을 재생합니다.
- **F-locked 경계:** 수소가 전극 몸체로 침투하는 것을 차단해 블리스터, 박리와 데브리 발생을 줄입니다.
- **환형 전극:** 광축 중심을 열어 전방 축방향 집광을 가능하게 합니다.
- **교체형 데브리 실드:** 집광계 방향 오염을 줄이면서 유지보수성을 확보합니다.

이들은 서로 분리된 제품 이야기가 아닙니다. **쿨스 특허 냉각기술로 허용전력을 높이는 동안 DPP 전극을 안정하게 유지하기 위한 하나의 통합구조**입니다.

## LPP와 쿨스 냉각 DPP 비교

| 항목 | LPP | 종래 DPP | 쿨스 냉각 DPP 개념 |
|---|---|---|---|
| 플라즈마 발생 | 비행 Sn 드롭릿에 CO₂ 레이저 조사 | 전기방전 | 전기방전 |
| 구동 레이저 | 필요 | 불필요 | 불필요 |
| 드롭릿 발생기 | 필요 | 불필요 | 불필요 |
| 주된 열병목 | 자유공간 광학환경 | 전극 침식 | 후방 전도냉각으로 배출 |
| 데브리 대응 | 대형 DMS 부담 | 역사적으로 치명적 | F-locked + 재생표면 + 실드 |
| 집광구조 | 자유공간 집광 | 전극 차폐 | 환형 축방향 집광 |
| 출력 확장경로 | 레이저·광학계 고출력화 | 전극 열에서 차단 | 전기입력·반복률 상승 |
| 시스템 복잡도 | 높음 | 낮음 | 낮음 |

## 전략적 의미

쿨스는 또 하나의 DPP 전극을 제안하는 것이 아닙니다.

> **DPP가 고출력화되지 못하게 막았던 바로 그 부품, 플라즈마 대면 전극에 쿨스 특허 전도냉각 아키텍처를 적용하는 것입니다.**

열천장이 제거되면 DPP는 LPP 대비 구조적 장점을 유지합니다.

- 직접 전기구동
- 메가와트급 CO₂ 레이저 체인 불필요
- 정밀 드롭릿 발생기 불필요
- 낮은 시스템 복잡도
- 작은 설치면적
- 고체를 통한 직접 열배출 경로

따라서 더 단순하면서도 더 높은 출력으로 확장 가능한 EUV 광원 아키텍처가 성립합니다.
